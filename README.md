# GG.Meter

Счётчик урона для **AION 2** — лёгкий оверлей поверх игры.

## Скачать

Последняя версия — на вкладке [**Releases**](../../releases/latest).

Скачай `.msi`, запусти. Больше ничего не нужно: WebView2 идёт
в комплекте с Windows 10 и новее.

При первом запуске Windows покажет «Неизвестный издатель» —
это нормально для программ без платной подписи. Нажми
«Подробнее» → «Выполнить в любом случае».

## Что умеет

- DPS каждого в группе, доля в общем уроне, боевая мощь
- Отдельный вид для PVP: ты, цель, атакующие
- Клик по игроку — полная выкладка: способности, криты,
  перфект, смайт, удары в спину, лечение, полученный урон
- Итоги боя и история последних боёв
- Русский и английский интерфейс

## Что метр НЕ делает

- Не читает память игры и не вмешивается в неё — только слушает
  сетевой трафик
- Не автоматизирует игру и не нажимает клавиши за тебя
- Ничего не отправляет наружу без явного согласия
