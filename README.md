# GG.Meter

Счётчик урона для **AION 2** — лёгкое окно поверх игры: DPS каждого в
группе, разбор боя по умениям, история боёв.

## Скачать

**[⬇ Скачать GG.Meter для Windows](https://github.com/ggplace/ggmeter-releases/releases/latest/download/GG.Meter-Setup.exe)**

Ссылка всегда ведёт на последнюю версию. Дальше метр обновляется сам.

## Установка

1. **Запусти `GG.Meter-Setup.exe`.** Windows может показать «Windows
   защитила ваш компьютер» — это обычное предупреждение для программ без
   платной подписи. Нажми «Подробнее» → «Выполнить в любом случае».
2. **Npcap.** Метру нужен бесплатный драйвер [Npcap](https://npcap.com) —
   через него метр видит трафик игры. Если его нет, установщик метра сам
   предложит скачать и запустить официальный установщик Npcap: подтверди
   запрос Windows и нажми Install. Пропустил — в метре нажми кнопку «i»
   рядом с «Нужен Npcap» → «Установить Npcap». С ExitLag нужен свежий
   Npcap: в нём захват через петлю работает сам.
3. **Запусти игру и зайди персонажем.** Метр сам найдёт игру и твоего
   персонажа. Чтобы проверить, что всё работает, — начни бой: ударь любого
   моба или чучело.

Нужна Windows 10 или 11 (64-бит). Права администратора не нужны.

Чтобы метр узнавал тебя сразу, без ожидания входа в мир, впиши свой ник:
**Настройки → Бой → «Мои персонажи»**.

## Что умеет

- DPS, урон и доля каждого в группе; иконки и названия классов
- HP цели — босса или моба — с процентом
- Отдельный вид для PvP: ты, твоя цель, кто бьёт тебя
- Щелчок по игроку — подробный разбор как в игровом «Анализе боя»:
  умения, криты, перфект, удары в спину, промахи, лечение, полученный урон
- История последних боёв
- Рейтинги по классам: урон по чучелу и в любых боях (бои от 30 секунд)
- Русский и английский интерфейс, названия умений и монстров из игры

## Что метр НЕ делает

- Не читает память игры и ничего в ней не меняет — только слушает
  сетевой трафик на твоём компьютере
- Не нажимает клавиши и не автоматизирует игру

## Какие данные уходят наружу

Для рейтингов метр отправляет **анонимные итоги PvE-боёв**: класс, урон,
длительность, босс. **Ники не отправляются** — ни твой, ни чужие. Кроме
этого метр только проверяет обновления, а если в разборе боя нажать «Найти
игрока» — ищет этого игрока по нику на stigma.pro.

## Если не работает

- **Висит «Поиск персонажа» или «Ищу игру…»** — нажми «i» рядом с надписью:
  там видно, чего не хватает. Начни бой — ударь любого моба или чучело.
- **Нужна помощь** — **Настройки → О программе → «Собрать диагностику»**:
  метр сложит журнал и настройки (без паролей и ключей) в папку. Пришли
  её в [Discord](https://discord.gg/diffaion2) и опиши, что происходит.
